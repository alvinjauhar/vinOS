# VinOS

VinOS is an operating system build from scratch for the x86-64 architecture, 
developed for learning and exploration purposes related to UNIX-like operating
systems and the x86-64 architecture. The ultimate goal is to create a minimal
operating system capable of running a few simple games.

## Progress

1. **Bootloader**
	- Transition from real mode to long mode
	- Kernel loading

2. **Physical Memory Allocator**
	- Custom implementation of 'kmalloc()' and 'kfree()'
	- Buddy allocation algorithm

3. **5-Level Paging**
	- Full 5-level paging support for x86-64

4. **VGA Text Mode**
	- Basic text-mode display output

5. **Simple Process Management**
	- 'fork()', 'exit()', 'wait()' system call

6. **Priority-Based Scheduler**
	- Task scheduling with priority levels
